# Online Retail Sales Dashboard

## Project Overview

This Power BI dashboard analyzes sales performance using the Online Retail dataset. The dashboard provides insights into revenue trends, customer activity, country performance, and product performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV

## Dashboard Pages

### Page 1: Executive Overview

- Total Revenue
- Total Customers
- Total Quantity Sold
- Revenue Trend Analysis
- Top Countries by Revenue

### Page 2: Product Performance Analysis

- Top 10 Products by Revenue
- Top 10 Products by Quantity Sold
- Product Performance Matrix
- Product Segmentation Analysis

## Key Insights

- Revenue is concentrated within a few top-performing products.
- Certain products generate high volumes but relatively low revenue.
- Product segmentation helps identify growth opportunities and underperforming products.
- Revenue trends provide visibility into business performance over time.
